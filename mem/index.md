# Project Memory

## Core
Produto: SaaS de organização de eventos (nasceu do 15 anos da Mirella, 02/10/2026). Nunca perder os dados desse evento.
Todo dado é isolado por `event_id`; acesso via `event_members` + RLS por papel no banco, não só na interface.
Idioma da interface: português do Brasil. Estética rosa claro/dourado.
